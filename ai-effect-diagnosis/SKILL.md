# AI效果诊断 Skill

## 用途

帮AI顾问快速分析客户的AI应用使用数据，生成初步诊断报告。

**适用场景**：
- 客户AI应用已上线，需要定期优化
- 获客工具（LinkedIn/邮件/WhatsApp）效果下滑
- 客服AI回复质量需要改进
- 不知道从哪里入手优化

## 使用方法

### 1. 采集客户数据

登录客户VPS，采集以下数据之一：

**A. 日志文件**（推荐）
```bash
# 示例：AI Hunter日志
tail -n 1000 /root/AI_Find_Customer/logs/app.log > ~/ai_data.log

# 示例：客服AI对话记录
cp /var/log/customer_service/*.json ~/ai_data.json
```

**B. 数据库导出**
```bash
# 示例：导出最近7天获客数据
sqlite3 /path/to/db.sqlite3 "SELECT * FROM leads WHERE created_at > datetime('now', '-7 days');" > ~/leads_7d.csv
```

**C. API响应数据**
```bash
# 示例：从API拉取使用统计（token存环境变量）
curl -H "Authorization: Bearer $API_TOKEN" https://api.example.com/stats > ~/api_stats.json
```

### 2. 跑诊断

```bash
hermes chat -m "用ai-effect-diagnosis分析 ~/ai_data.log，生成诊断报告"
```

或者直接传文件：

```bash
hermes chat -m "诊断这个AI应用的效果" --attach ~/ai_data.log
```

### 3. 输出格式

生成markdown报告包含：

```markdown
# AI效果诊断报告
生成时间：2026-09-17 14:30

## 数据概览
- 数据时间范围：2026-09-10 ~ 2026-09-17
- 总记录数：1,234
- 数据类型：LinkedIn获客日志

## 核心指标
| 指标 | 数值 | 环比 | 状态 |
|------|------|------|------|
| 日均触达量 | 87 | -23% | ⚠️ 下降 |
| 回复率 | 12.3% | +2.1% | ✅ 正常 |
| 转化率 | 3.8% | -1.2% | ⚠️ 下降 |

## 异常发现
1. **9月15日后触达量骤降**
   - 原因：可能触发LinkedIn限流
   - 数据支撑：15日后日均87 vs 之前156

2. **周末转化率低50%**
   - 原因：周末目标客户不活跃
   - 数据支撑：周六日3.8% vs 工作日7.2%

## 多维切分
### 按行业
- 制造业：转化率8.1%（高）
- 零售业：转化率2.3%（低）

### 按消息模板
- 模板A：回复率18%（最佳）
- 模板B：回复率6%（最差）

## 优化方向
1. **立即处理**：检查LinkedIn账号状态，确认是否被限流
2. **本周优化**：周末暂停发送，集中工作日
3. **长期改进**：针对零售业重写消息模板，参考制造业高转化话术
```

### 4. Review后发客户

**关键**：这份报告是初步分析，你需要：
1. 检查数据解读是否合理
2. 把"优化方向"改成**可执行的具体动作**
3. 删掉客户看不懂的技术术语
4. 加上你的专业判断

然后发给客户：
```
老板你好，这是本周AI效果分析：

【核心问题】
9月15日后获客量下降23%，可能触发LinkedIn限流。

【数据支撑】
- 15日前日均156次触达，15日后降到87次
- 但回复率反而上升2.1%，说明消息质量没问题

【建议动作】
1. 今天：我登你账号检查LinkedIn状态，看有没有限流警告
2. 本周：调整发送节奏，从每天150次降到100次
3. 下周：测试新节奏7天，我再出一份对比报告

需要我现在就处理吗？
```

## 支持的数据格式

| 格式 | 示例 | 适用场景 |
|------|------|----------|
| JSON | `{"timestamp": "...", "event": "..."}` | API响应、结构化日志 |
| CSV | `日期,事件,结果` | 数据库导出 |
| 纯文本日志 | `[2026-09-17 14:30] INFO: ...` | 应用日志文件 |
| SQL dump | `INSERT INTO ...` | 数据库完整导出 |

## 技术实现

Skill会自动：
1. 识别数据格式（JSON/CSV/日志/SQL）
2. 提取时间序列（按天/周聚合）
3. 计算核心指标（量/率/转化）
4. 多维切分（时间/类型/来源/模板）
5. 异常检测（环比下降>15%标记）
6. 生成可执行建议（不是泛泛而谈）

## 常见问题

**Q: 数据太少怎么办？**
A: 至少需要3天数据。少于100条记录会提示"数据不足，建议采集更多"。

**Q: 数据格式乱怎么办？**
A: 先用`head -20 ~/ai_data.log`看几行，告诉Hermes数据结构，它会自动适配。

**Q: 能自动发客户吗？**
A: 不能。这个skill只生成初步分析，必须你review后再发。

**Q: 能对比多个时间段吗？**
A: 可以。准备两份数据文件（如`week1.csv`和`week2.csv`），让Hermes对比分析。
